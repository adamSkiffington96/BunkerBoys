
# Bunker Boys

- A text adventure with a highly-repeatable template system and node-based elements
- Developers may create empty story objects (or nodes), which may be filled and added to the tree
![App Screenshot](https://i.imgur.com/UM8GMHD.png)
- Since the story is in the form of a hierachical tree, all plots start from the root node at a depth of 0
- From the initial node, a developer may add an indefnite number of connecting nodes, or 'story-elements,' to each proceeding node
- The tree has an indefinite depth and allows for many different final story endings, side missions, dead ends, or special scenarios.
- Games like FTL and Slay The Spire have a similar staging system, usually connected to the viewable map
